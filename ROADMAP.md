# Roadmap

Quiet House is intentionally narrow. This roadmap states possible review targets, not delivery promises.

## Alpha 1: public maintainer surface

- Maintain a synthetic-only public repository under the approved Source and privacy boundaries.
- Run no-model CI across supported Python versions.
- Collect reproducible bug and route/interrupt misclassification reports.

## Alpha 2: stronger local evidence

- Add schema-level receipt validation and explicit provenance fields.
- Add more no-model boundary fixtures without expanding external-action authority.
- Document fail-closed behavior for malformed or incomplete decisions.

## Later research questions

- How should attention cost be evaluated without manufacturing superiority claims?
- Which operator-facing explanations help people distinguish permission from urgency?
- What additional local-only adapters can preserve the same hard gates?

## Out of scope unless separately approved

- production deployment;
- real-account or customer-data workflows;
- unattended external actions;
- automatic retry, repair, reprompt, or provider fallback;
- security-certification or model-superiority claims.
