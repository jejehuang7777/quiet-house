# Security Policy

## Supported status

Quiet House is pre-release alpha software. It is not approved for secrets, real accounts, customer data, personal data, external actions, or production deployment.

## Reporting a vulnerability

Use this repository’s private GitHub Security Advisory form. Do not post exploit details, credentials, personal data, or private paths in a public issue.

This repository intentionally does not publish an owner email address; private security reports should use GitHub Security Advisories.

Include a minimal synthetic reproduction, affected version or commit, impact, and suggested mitigation if known. Receipt integrity, route/interrupt separation, path handling, and accidental external-action paths are in scope.

## Important limitation

This policy is a reporting process, not a security certification or service-level commitment.
